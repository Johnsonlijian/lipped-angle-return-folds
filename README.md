# Return-fold mode exchange: computational archive

Version 1.0.0 (12 November 2026). Repository: https://github.com/Johnsonlijian/lipped-angle-return-folds .

Code and derived outputs for the local research manuscript *Local–distortional mode exchange in long-lip angle sections with return folds: a thickness-scaled threshold and its direct-strength implications*. No publication or acceptance is claimed.

The core application scripts and modified solver are in src/ and vendor/. data/ holds derived spectrum/threshold/DSM tables. gmnia/ holds 48 input configurations and extracted outputs. figures/ contains the twelve numerical figures. inherited/ supplies the previously computed elastic ratio and shell comparison tables. Figure 12 is regenerated by src/make_final_gmnia.py. Peak-only statistics distinguish 43 resolved campaign cases from five attained-load lower bounds; 33 of 37 baseline cases have resolved peaks.

The author approved public release and component-specific licences on 12 November 2026: MIT for original scripts and input decks; CC BY 4.0 for original derived numerical tables, result metadata, figures and documentation; AFL 3.0 retained for PyCUFSM 0.2.0. The paper, cover letter, author/funding records, private software records, third-party PDFs, raw downloaded datasets and submission metadata are excluded. See REPRODUCIBLE_RUNBOOK.md and THIRD_PARTY_NOTICES.md.

The inherited elastic shell archive includes 39 exact final eigenproblem inputs and three static preload inputs, their metadata, independent shell mesh generators, extraction and MAC-comparison scripts.

Versioned archive: https://doi.org/10.5281/zenodo.24154606 . Component-specific terms are in LICENSE and LICENSES/.
